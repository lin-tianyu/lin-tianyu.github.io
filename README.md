## Tianyu's Personal Website

- Thanks to the open source website template [PRISM](https://github.com/xyjoey/PRISM).

### Run locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser. To verify a production build and run it locally:

```bash
npm run build
npm start
```
